# Критерии готовности

Статус отражает текущее состояние. ✅ — выполнено, ⏳ — частично/в работе,
⬜ — не начато.

## Базовый сервис
- [x] Стек поднимается на Raspberry Pi 4 (arm64), контейнеры healthy.
- [x] Open WebUI доступен по HTTPS, WebSocket/SSE работают.
- [x] PostgreSQL и Qdrant используются как хранилища (без SQLite для ядра).
- [x] Rootless Docker, data-root/тома на `${DATA_ROOT}`.
- [x] Бэкапы (`pg_dump`, снапшот Qdrant) и smoke-тесты.
- [x] Продление TLS (certbot + cron), базовый hardening (UFW, права файлов).

## Доступ и пользователи
- [x] Публичная регистрация Open WebUI выключена.
- [x] Регистрация по токену и вход по логину (портал).
- [x] Изоляция пользователей: свои чаты/настройки/данные в рамках аккаунта.
- [x] Telegram-бот: allowlist/код подтверждения, соответствие аккаунтам.
- [x] Android-приложение: вход тем же аккаунтом, авторизация Bearer.

## Функциональность
- [x] Календарь (события) и задачи (Vikunja), управление в вебе/приложении/API.
- [x] Веб-поиск (DuckDuckGo, настраиваемо).
- [x] Голос: STT и TTS (API, контейнеры); проверка в клиентах — по сценариям.
- [x] MCP-инструменты: vault, files, github, vikunja, sandbox (с ограничениями).
- [x] Брифинг и напоминания (Telegram, приложение — локально/через API).
- [x] Пресеты и режимы чатов (в т.ч. приватный/временный).

## Obsidian
- [x] Серверный вольт владельца: подключение, синхронизация, индексация.
- [x] Персональный вольт пользователя: репозиторий + PAT, изоляция хранения.
- [x] Права по папкам (read/list/search/create/append/update/delete),
      программная проверка на сервере при каждом действии.
- [x] Поиск/чтение и запись по прямой команде, коммит/push (при включении).
- ⏳ Per-user контекст для MCP-инструментов в веб-чате.

## Android (MVP)
- [x] Клиент собирается в CI, APK распространяется (артефакт/Releases).
- [x] Чаты (SSE), выбор модели, приватный чат.
- [x] Голос STT/TTS, hands-free (логика реализована).
- [x] «Сегодня»: сводка, события, задачи, напоминания (CRUD/управление).
- [x] Заметки Open WebUI и личный Obsidian-вольт (просмотр/поиск/запись).
- [x] Вложения, камера, OCR (ML Kit), шаринг из других приложений.
- [x] Виджет/плитка/ярлыки/deep links (в коде).
- [x] Биометрия, FLAG_SECURE в приватном чате, Material You/Gruvbox.
- [x] Действия на устройстве (таймер, будильник, открыть приложение, поиск и др.).
- ⏳ Полный прогон на реальном устройстве (разрешения, фон, версии Android).
- ⏳ Полный оффлайн-кэш/очередь для всех действий, доступность (TalkBack).
- ⏳ Подписанный релиз (keystore), ntfy end-to-end.

## Безопасность и эксплуатация
- [x] Секреты вне git, права 600, шифрование чувствительных токенов в БД.
- [x] Сети/лимиты контейнеров, изоляция MCP, без публикации БД наружу.
- [x] HTTPS, HSTS/редирект (по конфигурации), защита форм (CSRF/Origin где применимо).
- [x] Документация актуализирована (README, docs/*).
- ⏳ Регулярный аудит зависимостей/образов, автоматизация обновлений.

## Известные ограничения
- CalDAV-синхронизация событий Open WebUI отсутствует в v0.13.3 (ADR-016).
- MCP-вольт в веб-чате не полностью per-user.
- Сборка APK на Pi не поддерживается как штатный процесс.
- Полноценная приёмка мобильного UX требует тестов на устройстве.

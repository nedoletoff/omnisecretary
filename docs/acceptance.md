## Приёмка этапа 1 (детально)

- [ ] `docker compose config -q` без ошибок.
- [ ] 5 контейнеров в состоянии `running`, у 4 — `healthy`.
- [ ] `http://<pi>/healthz` → `ok`.
- [ ] `http://<pi>/health` → JSON Open WebUI.
- [ ] Первый пользователь создан, вход работает.
- [ ] Чат с облачной LLM отвечает.
- [ ] Регистрация закрыта (вторая попытка signup невозможна).
- [ ] `make smoke` — 0 ошибок.
- [ ] `make backup` создаёт файлы в `${DATA_ROOT}/backups`.
- [ ] После `sudo reboot` стек поднимается сам.
- [ ] `docker stats --no-stream` — суммарное потребление в норме.

## Как фиксируем результат

Для каждого закрытого пункта — строка в этом файле с датой и ссылкой на
коммит/скрин. Этап считается принятым, когда все его пункты отмечены.

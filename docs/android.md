# Android-приложение OmniSecretary

Нативный клиент для Android (Jetpack Compose). Приложение подключается к
вашему серверу OmniSecretary и даёт доступ к ассистенту, календарю, задачам,
заметкам, личному Obsidian-вольту и голосу с телефона.

- **Пакет:** `ru.nedoletoff.omnisecretary`
- **Версия:** 0.1.0-beta (versionCode 10)
- **Минимум:** Android 8.0 (API 26), **целевая:** API 37
- **Сервер по умолчанию:** `https://nedoletoff.sknt.ru`
- **Сборка:** GitHub Actions, артефакт APK и релизы по тегу `android-v*`

Исходники: `android/`. ТЗ и история: [mobile-android.md](mobile-android.md).

## Возможности

### Ассистент и чаты
- Вход тем же логином и паролем, что в веб-интерфейсе (Open WebUI).
- Список чатов, создание и удаление, обычные и **приватные** (временные,
  не сохраняются).
- Потоковые ответы (SSE), выбор модели/пресета.
- Голосовой ввод (STT) и озвучка ответа (TTS), **hands-free** режим
  (ответ → озвучка → автопрослушивание).
- Вложения: файлы, изображения, фото с камеры; отправка в чат.
- OCR: распознавание текста с изображения (ML Kit, офлайн) и вставка в
  поле ввода.
- Сохранение ответа ассистента в заметку.
- Шаринг текста/изображений/файлов из других приложений в чат.

### Действия на устройстве (ассистентные команды)
В чате распознаются явные команды и выполняются через системные интенты:
- таймер: `таймер на 5 минут`
- будильник: `будильник на 07:30`
- открыть приложение: `открой YouTube`, `запусти карты`
- поиск: `найди в интернете ...`, `загугли ...`
- маршрут: `маршрут до ...`
- звонок: `позвони +7...`

Панель быстрых действий (⋮⋮ в шапке чата): таймер, будильник, открытие
приложения, поиск, часы, маршрут.

### «Сегодня»
- Сводка: погода, события, задачи, заметки.
- Быстрые действия: заметка в Obsidian, напоминание, событие, задача.
- Календарь: создание, просмотр, редактирование (название/описание),
  удаление событий.
- Задачи (Vikunja): создание, выполнение, редактирование (название/срок),
  удаление.
- Напоминания: создание (локально и/или в Telegram), список, удаление.

### Заметки и Obsidian
- **Заметки Open WebUI:** просмотр, создание, редактирование, удаление.
- **Личный Obsidian-вольт** (настраивается пользователем): просмотр
  файлов, поиск, чтение заметок.
  - Репозиторий и GitHub PAT добавляет сам пользователь в приложении.
  - Права по папкам настраиваются пользователем (чтение, список, поиск,
    создание, дополнение, изменение, удаление) и **проверяются
    программно на сервере** при каждом действии.
  - Запись заметок в `AI/*` (с коммитом и push) — по прямой команде.
- Для владельца также доступен просмотр подключённого общего вольта
  (если настроен на сервере).

### Запуск «в одно действие»
- Виджет, QS-плитка, ярлыки, deep links (`omnisecretary://voice`,
  `omnisecretary://today`, `omnisecretary://chat`, `omnisecretary://note`).
- Share target: текст/изображения/файлы из других приложений.

### Оформление и настройки
- **Темы:** Gruvbox (фирменная) и **Material You** (динамические цвета
  системы/обоев, Android 12+), светлая/тёмная по системе. Палитры тем
  независимы, акценты и поверхности гармонизированы.
- Модель по умолчанию, уведомления (приложение и Telegram — раздельно),
  настройки ntfy (сервер/topic).
- **Безопасность:** биометрическая блокировка при входе и при возврате
  из фона (опция), `FLAG_SECURE` в приватном чате, токен в
  `EncryptedSharedPreferences`, только HTTPS.
- Статус устройства (для владельца): температура, память, диски,
  контейнеры, сертификат, бэкапы.

### Офлайн-поведение
- При отсутствии сети заметки в Obsidian и напоминания ставятся в
  локальную очередь, выполняются при подключении (авто/повтор), есть
  индикатор.
- Полный оффлайн-кэш чатов/списков и единая очередь для всех действий —
  в планах доработки.

## Установка

### Из GitHub Releases (рекомендуется)
1. Откройте [Releases](https://github.com/nedoletoff/omnisecretary/releases)
   и скачайте APK тега `android-v*` (например, `android-v0.1.0-beta`).
2. На телефоне разрешите установку из неизвестных источников для
   браузера/файлового менеджера.
3. Откройте APK и установите.

### Из артефакта CI
**Actions → android →** нужный успешный запуск → скачать артефакт
`omnisecretary-debug` → установить `app-debug.apk`.

### Локально с сервера
Готовая debug-сборка (если есть) может лежать на Pi:
`/home/nedoletoff/omnisecretary/android/app/build/outputs/apk/debug/app-debug.apk`

## Первый запуск и вход

1. **Сервер:** `https://nedoletoff.sknt.ru` (по умолчанию).
2. **Вход:** логин и пароль аккаунта Open WebUI.
   - Владелец: логин `nedoletoff`, пароль — на сервере в
     `/srv/omnisecretary/secrets/webui-owner.txt` (команда `make owner-creds`).
3. **Нет аккаунта:** регистрация по токену приглашения —
   `https://nedoletoff.sknt.ru/register`. Токен: `.env` → `TELEGRAM_CONFIRM_CODE`
   или `/srv/omnisecretary/secrets/telegram-confirm-code.txt`.
4. После входа: вкладки **Чаты**, **Сегодня**, **Заметки**, **Настройки**.

Секреты не храните в переписках; берите из файлов на сервере.

## Настройка личного Obsidian-вольта

1. **Заметки → Obsidian → Настроить вольт**.
2. URL репозитория (`https://github.com/<user>/<vault>.git`), ветка, GitHub PAT
   (fine-grained, Contents: read/write на этот репозиторий).
3. Настройте **права по папкам** (префиксы): для каждого правила — чтение,
   список, поиск, создание, дополнение, изменение, удаление.
4. **Сохранить и подключить** — сервер клонирует репозиторий и построит индекс.

**Важно:**
- Права применяются **программно на сервере** на каждое действие; промпт
  ассистента их не обходит. При отсутствии разрешающего правила доступ
  запрещён.
- Применяется самое точное (длинное) совпадающее правило.
- По умолчанию: чтение/поиск всего; создание/дополнение/изменение в `AI/`;
  удаление выключено. Для приватных папок снимите галочки.
- Токен хранится зашифрованным на сервере, не попадает в git и логи.
- У каждого пользователя — свой вольт и свои права (изолированно).

## Сборка и релизы

### CI (GitHub Actions)
- Workflow: `.github/workflows/android.yaml` (если настроен в репозитории),
  эталон: `android/ci/github-actions-android.yml`.
- Триггеры: push в `android/**` или workflow, теги `android-v*`, ручной запуск.
- Раннер: `ubuntu-latest`, JDK 21 (Temurin), Gradle **9.9.1**.
- Результат: debug APK (артефакт `omnisecretary-debug`), при теге —
  вложение в GitHub Release.

**Требования к workflow:** `permissions: contents: write` (для релиза),
актуальная версия Gradle (≥ требуемой AGP). При ошибке
`Resource not accessible by integration` — добавить `permissions` и/или
включить «Read and write permissions» в Settings → Actions → General.

### Локальная сборка (не рекомендуется на Pi)
Сборка на Raspberry Pi возможна, но тяжёлая (RAM/время, эмуляция aapt2).
Штатный путь — CI. При необходимости: Gradle 9.9.1, JDK 21, Android SDK.

### Подпись релиза
Для подписанного APK/AAB задайте в `gradle.properties` или переменных
окружения (Secrets CI): `RELEASE_STORE_FILE`, `RELEASE_STORE_PASSWORD`,
`RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`. Конфиг в
`android/app/build.gradle.kts`.

### Версионирование
- `versionName` / `versionCode` — в `android/app/build.gradle.kts`.
- Теги релизов: `android-v<version>` (например, `android-v0.1.0-beta`).

## API сервера (для клиента)

Приложение использует Open WebUI API (чаты, модели, SSE, заметки,
календарь, память) и мобильные эндпоинты портала:

| Эндпоинт | Назначение |
|---|---|
| `GET /api/m/today` | сводка дня |
| `GET /api/m/status` | статус устройства (владелец) |
| `POST /api/m/voice`, `/api/m/speak` | STT/TTS |
| `POST /api/m/note` | заметка в `AI/*` вольта (+ коммит/push) |
| `GET/POST /api/m/event*` | события календаря |
| `GET/POST /api/m/task*` | задачи Vikunja |
| `GET/POST /api/m/notes*` | заметки Open WebUI |
| `GET/POST /api/m/reminder*` | напоминания |
| `GET/POST /api/m/vault/*` | личный вольт, права, файлы, поиск, синхронизация |

Авторизация — Bearer-токен пользователя Open WebUI. Данные изолированы
по аккаунту.

## Известные ограничения

- Полноценный прогон на реальном устройстве обязателен: виджет/плитка,
  разрешения, камера, биометрия, фоновые уведомления, голос на разных
  версиях Android.
- Офлайн: очередь есть для заметок в вольт и напоминаний; полный кэш и
  очередь для всех действий — доработка.
- OCR — распознавание с изображения (вставка текста), без отдельного
  сканер-режима.
- MCP-инструменты вольта в веб-чате пока работают с общим вольтом; в
  приложении и `/api/m/vault/*` используется персональный вольт с правами.
- Локальная сборка на Pi тяжёлая; используйте CI.

## Безопасность

- Без секретов в APK; трафик только HTTPS.
- Приватный чат: не сохраняется, экран защищён `FLAG_SECURE`.
- Токен сессии — в `EncryptedSharedPreferences`.
- Права доступа к папкам вольта проверяются на сервере, не на клиенте.
- GitHub PAT вольта хранится зашифрованным на сервере.

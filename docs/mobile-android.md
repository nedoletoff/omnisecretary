# ТЗ: Android-приложение OmniSecretary

Статус: **проект ТЗ, реализация не начата**. Дата: 18.11.2026.

## 1. Цель

Дать телефону полноценного ассистента уровня Gemini: запуск **в одно
действие**, голосовой диалог, работа с календарём, задачами, заметками и
файлами, плюс фирменные возможности OmniSecretary (пресеты, приватный
режим, Obsidian, брифинг, состояние Pi).

Ключевое отличие от «просто сайта в браузере»: иконка на рабочем столе,
виджет и плитка быстрых настроек, голосовой старт без открытия чата,
шаринг текста/ссылок/фото из других приложений, уведомления.

## 2. Пользователи и сценарии

| Сценарий | Ожидаемое поведение |
|---|---|
| «Спросить голосом» | Долгое нажатие иконки/виджет → сразу слушает → ответ голосом и текстом |
| «Что у меня сегодня» | Виджет/плитка → экран «Сегодня»: погода, события, задачи, напоминания |
| «Запиши мысль» | Поделиться текстом из любого приложения → заметка в `AI/Inbox` |
| «Напомни» | Фраза голосом → напоминание в Telegram и локальным уведомлением |
| «Приватно» | Переключатель приватного режима → чат не сохраняется, память не используется |
| «Смени лицо» | Быстрое переключение пресета (OmniSecretary/Secretary/Archivist/Coder/Private) |

Целевая аудитория: 1–3 человека (владелец + близкие), русский язык,
Android 8.0+.

## 3. Архитектура

### 3.1. Выбранный подход

**Capacitor-обёртка над мобильным веб-интерфейсом** + нативные модули для
того, что веб не умеет.

```
┌──────────────────────────────────────────────┐
│ Android APK (Capacitor 7, Kotlin/Java)       │
│  ├─ WebView → https://nedoletoff.mooo.com/m  │
│  ├─ Native: виджет, QS-плитка, ярлыки,        │
│  │   share target, push, биометрия, запись    │
│  └─ Deep links: omnisecretary://…             │
└──────────────────────────────────────────────┘
              │ HTTPS (существующие API)
┌─────────────▼────────────────────────────────┐
│ Pi: nginx → portal (/m, /api/m/*) + Open WebUI│
│     STT (omni-stt), TTS (omni-tts), Vikunja,  │
│     календарь, вольт, бот                     │
└──────────────────────────────────────────────┘
```

Почему так:

- уже есть HTTPS, авторизация, изоляция пользователей и все функции —
  дублировать бэкенд не нужно;
- Capacitor даёт нативные виджеты, плитку, шаринг, пуши и биометрию без
  переписывания UI на Kotlin;
- веб-часть можно обновлять без выпуска APK;
- TWA (Bubblewrap) отклонён: не даёт виджетов и плитки, ограничен в
  нативных вызовах.

Нативная UI-разработка на Compose отклонена на этом этапе: в 3–4 раза
дороже, а выигрыш в UX для одного пользователя не оправдан. Порог входа
оставлен: если WebView окажется медленным на голосе, экран голосового
режима переписывается на нативный.

### 3.2. Сборка

- Исходники: `android/` (Capacitor-проект), `mobile/` (веб-часть `/m`).
- Сборка **в GitHub Actions** (JDK 21 + Android SDK), не на Pi: Gradle
  съест всю память.
- Артефакты: `app-debug.apk` для установки вручную, `app-release.aab` —
  позже, при публикации.
- Подпись: keystore в GitHub Secrets, не в репозитории.
- Версионирование: `versionName` = версия проекта, `versionCode` —
  монотонный счётчик.

## 4. Функциональные требования

### 4.1. Запуск в одно действие (M3)

1. **Иконка** с Gruvbox-оформлением и adaptive icon.
2. **Ярлыки** (long press иконки): «Голос», «Новый чат», «Сегодня»,
   «Заметка».
3. **Виджет 1×1**: одно нажатие → голосовой режим.
4. **Виджет 2×1**: «Сегодня» + микрофон.
5. **Quick Settings tile**: плитка в шторке → голос.
6. **Share target**: принять `text/plain`, `text/uri-list`,
   `image/*` → отправить в чат или в `AI/Inbox`.
7. **Deep links**: `omnisecretary://voice`, `/chat`, `/today`,
   `/note?text=…`, `/reminder?text=…`.
8. **Возврат в приложение** из уведомления сразу в нужный экран.

Ограничение, которое фиксируем честно: заменить системную кнопку
ассистента («Hey Google»/боковая кнопка) на всех устройствах нельзя.
Ярлык, виджет и плитка — универсальный эквивалент.

### 4.2. Экраны

| Экран | Содержимое |
|---|---|
| **Онбординг** | адрес сервера, вход логином, проверка HTTPS, разрешения (микрофон, уведомления) |
| **Ассистент (главный)** | большая кнопка микрофона, поле ввода, последние чаты, переключатель пресета и приватного режима |
| **Чат** | потоковый ответ, Markdown, код, вложения, цитаты из вольта, кнопки «в календарь», «в задачу», «в заметку» |
| **Голос** | волна записи, распознанный текст, ответ TTS, кнопка «прервать», автопродолжение диалога |
| **Сегодня** | погода, события дня, задачи Vikunja, напоминания, последние заметки |
| **Заметки** | поиск по вольту, чтение, создание в `AI/Inbox`, цитирование в чат |
| **Календарь** | список и создание событий, выбор календаря |
| **Задачи** | списки Vikunja, создание, отметка выполнения, срок |
| **Настройки** | пользователь, город, пресет по умолчанию, каналы уведомлений, тема, выход |
| **Устройство** (только владелец) | температура, память, диск, контейнеры, сертификат |

### 4.3. Функции «как у Gemini»

- потоковый текстовый чат с историей;
- голосовой ввод и озвучка ответа (русский, `omni-stt` / `omni-tts`);
- голосовой диалог без рук: ответ → автоматически слушает дальше;
- вложения: фото, файл, скриншот;
- камера: снимок → OCR или отправка в модель со зрением (когда будет
  платная модель);
- история чатов, поиск, переименование, удаление;
- быстрые подсказки (suggestions) под полем ввода;
- шаринг ответа наружу;
- тёмная тема (Gruvbox), крупные тач-таргеты, работа одной рукой.

### 4.4. Фирменные функции OmniSecretary

- **Пресеты** — переключение лица в один тап, запоминание последнего.
- **Приватный режим** — визуальная метка, чат не сохраняется, память и
  история не читаются; при выходе из режима — очистка локального кэша.
- **Obsidian** — запись только по прямой команде, папка `AI/*`,
  подтверждение перед изменением существующей заметки.
- **Календарь и задачи** — создание на естественном языке, показ в
  «Сегодня».
- **Брифинг** — просмотр утренней сводки в приложении, даже если
  Telegram недоступен.
- **Напоминания** — локальные уведомления + Telegram, snooze.
- **Состояние Pi** — для владельца: температура, память, диск, сервисы.
- **Экономия контекста** — приложение не грузит вольт целиком: поиск →
  1–2 заметки → цитата.

## 5. Нефункциональные требования

| Параметр | Требование |
|---|---|
| Холодный старт | ≤ 2 с до готового поля ввода (кеш оболочки) |
| Голос | ≤ 1.5 с от конца речи до текста; ответ начинает звучать ≤ 2 с |
| Сеть | только HTTPS, cleartext запрещён, `network_security_config` |
| Оффлайн | оболочка и последние чаты открываются, отправка — в очередь |
| Батарея | никаких фоновых опросов чаще 60 с; пуши вместо polling |
| Память | ≤ 250 МБ RSS в обычной работе |
| Размер APK | ≤ 25 МБ |
| Доступность | контраст ≥ 4.5:1, тач-таргеты ≥ 48 dp, TalkBack |
| Язык | русский по умолчанию, строки вынесены в ресурсы |
| Приватность | скриншоты приватного чата запрещены (`FLAG_SECURE`) |

## 6. Аутентификация и изоляция

- Вход: логин + пароль через существующий портал, сессия — подписанная
  cookie в WebView; пароль в приложении не хранится.
- Дополнительно: биометрическая разблокировка приложения
  (`BiometricPrompt`), PIN как резерв.
- Токены и кэш — `EncryptedSharedPreferences`, не в открытом виде.
- Мультипользовательность: у каждого свой вход, свои чаты, календарь,
  задачи, память; приложение не смешивает данные между аккаунтами.
- Выход: очистка cookie, кэша WebView, локальной БД, очереди отправки.
- В APK нет ни одного секрета: ни API-ключей, ни паролей, ни токенов.

## 7. Push-уведомления

| Вариант | Плюсы | Минусы | Решение |
|---|---|---|---|
| **FCM** | нативно, надёжно | нужен Firebase-проект и `google-services.json`, зависимость от Google | отложено |
| **ntfy** (self-hosted) | без Google, простой HTTP | свой контейнер (+30 МБ), приложение ntfy или свой приёмник | кандидат |
| **Telegram** | уже работает | нужен Telegram | **сейчас** |
| Локальные (`AlarmManager`) | без сети | только по расписанию устройства | **сейчас** для напоминаний |

План: M5 — локальные напоминания и Telegram; ntfy — если понадобятся пуши
при закрытом приложении без Telegram; FCM — только при публикации в
Google Play.

## 8. API, который нужен от бэкенда

Существующего портала почти достаточно; добавить:

| Метод | Назначение |
|---|---|
| `GET /m` | мобильная оболочка (HTML+CSS+JS, без сборки) |
| `POST /api/m/voice` | аудио → текст (прокси на `omni-stt`) |
| `POST /api/m/speak` | текст → аудио (прокси на `omni-tts`) |
| `GET /api/m/today` | погода + события + задачи + напоминания одним ответом |
| `POST /api/m/note` | текст → заметка в `AI/Inbox` + git-коммит |
| `POST /api/m/reminder` | текст + время → напоминание |
| `GET /api/m/status` | состояние Pi (только владелец) |
| `POST /api/m/chat` | прокси в Open WebUI с выбранным пресетом (SSE) |

Требования: те же cookie-сессии и CSRF, что у портала; лимиты размера
аудио (10 МБ) и частоты (30 запросов/мин); ошибки в JSON.

## 9. Этапы

| Этап | Содержание | Критерий готовности |
|---|---|---|
| **M0** | это ТЗ, согласование решений | документ принят |
| **M1** | `/m`: мобильная оболочка, PWA-манифест, service worker, deep-link роуты | открывается на телефоне, устанавливается как PWA, ярлыки работают |
| **M2** | Capacitor-проект, CI-сборка APK, иконки/splash Gruvbox | APK ставится, открывает `/m`, вход работает |
| **M3** | виджет 1×1 и 2×1, QS-плитка, ярлыки, share target | голос запускается с домашнего экрана и из шторки |
| **M4** | голосовой режим: запись → STT → ответ → TTS, автопродолжение | диалог без рук на русском |
| **M5** | «Сегодня», календарь, задачи, заметки, напоминания | создание события/задачи/заметки из приложения |
| **M6** | камера, файлы, OCR, вложения; приватный режим, биометрия | фото → текст; приватный чат не сохраняется |
| **M7** | полировка: оффлайн, очередь, ошибки сети, доступность | приёмка по разделу 10 |

## 10. Критерии приёмки

1. Приложение ставится из APK, запускается и входит существующим логином.
2. С домашнего экрана одно нажатие открывает голосовой ввод; ответ
   звучит на русском.
3. Из любого приложения «Поделиться» → OmniSecretary создаёт заметку в
   `AI/Inbox` с git-коммитом.
4. Экран «Сегодня» показывает погоду, события и задачи; создание события
   и задачи работает.
5. Приватный режим: чат не появляется в истории, память не используется.
6. Пресет переключается в один тап и сохраняется между запусками.
7. Уведомление-напоминание приходит при закрытом приложении.
8. Второй пользователь видит только свои данные.
9. В APK нет секретов, трафик только HTTPS, приватные экраны без
   скриншотов.
10. Холодный старт ≤ 2 с, голос ≤ 1.5 с до текста на домашней сети.

## 11. Риски

| Риск | Митигация |
|---|---|
| WebView тормозит на Pi-бэкенде | кеш оболочки, ленивая загрузка, нативный экран голоса при необходимости |
| Провайдер блокирует push | Telegram + локальные уведомления как основной канал |
| Google Play требует политику и подпись | на первом этапе распространяем APK напрямую |
| Сборка на Pi невозможна | сборка в GitHub Actions |
| Виджет/плитка требуют нативного кода | отдельные Kotlin-модули, минимальная площадь |
| Модель без зрения | OCR локально/на сервере до появления платной модели |

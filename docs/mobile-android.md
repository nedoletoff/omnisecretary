# Мобильное приложение OmniSecretary (Android)

Статус: **реализуется** (MVP собран, версия 1.0.4-beta, CI и релизы настроены).  
Актуальная документация по установке, функциям и сборке: [android.md](android.md).

Документ фиксирует исходное ТЗ, архитектурные решения и план этапов M0–M7.

## Исходное ТЗ

- **Устройства:** Android (приоритет), целевой UX — как мобильный ассистент
  уровня Gemini, с «одной кнопкой» и быстрыми действиями.
- **Офлайн/онлайн:** полный функционал при доступе к серверу по HTTPS;
  локально — кэш, очередь отправки и быстрые действия где возможно.
- **Аутентификация:** те же аккаунты, что в Open WebUI (логин/пароль),
  изоляция данных по пользователям.
- **Что должно работать:** чат с ассистентом, голос, камера/файлы, заметки
  Obsidian, календарь, задачи, напоминания/уведомления, поиск в истории,
  переключение пресетов/режимов, приватный режим.
- **Ограничения:** Pi 4, 4 ГБ ОЗУ; сборка APK не на Pi; секреты не в
  репозитории; версии зафиксированы.

## Принятые решения (M0)

| Вопрос | Решение | Причина |
|---|---|---|
| Подход | **Capacitor-обёртка** над мобильным веб-интерфейсом + нативные модули Android | Бэкенд и UI уже есть; нативное пишем только там, где веб не умеет |
| «Одна кнопка» | Иконка, виджет, QS-плитка, ярлыки, deep links, share target | Универсально на Android |
| Голос | Микрофон в приложении → `/api/m/voice` (STT), ответ → `/api/m/speak` (TTS) | Единый стек с сервером |
| Пуши | **Telegram + локальные** уведомления; опционально **ntfy** | Без зависимости от Google/FCM |
| Уведомления | Каналы приложения и Telegram **раздельно** | Разные сценарии |
| Сборка | **GitHub Actions** (x86-64) | На Pi не собирать |
| Раздача | APK локально и через **GitHub Releases** | Просто обновлять |
| Имя/пакет | **OmniSecretary**, `ru.nedoletoff.omnisecretary` | — |
| Сервер по умолчанию | `https://nedoletoff.sknt.ru` | Стабильный доступ |
| Тема | Gruvbox и **Material You** (динамические цвета) | Системная интеграция без конфликтов палитр |

Фактическая реализация: нативный клиент на **Jetpack Compose** (Kotlin),
интеграция с Open WebUI API и мобильным API портала (`/api/m/*`).

## Архитектура клиента

```
Android (Compose)
 ├─ UI: Чаты, Сегодня, Заметки, Настройки, онбординг
 ├─ Голос: запись → STT, воспроизведение TTS, hands-free
 ├─ Локально: сессия (EncryptedSharedPreferences), очередь (заметки/напоминания)
 ├─ Система: виджет, QS-плитка, ярлыки, share, deep links, уведомления, биометрия
 └─ API:
     ├─ Open WebUI (/api/*, SSE chat/completions)
     └─ Портал (/api/m/*): today, status, voice/speak, notes, events, tasks,
        reminders, note→vault, per-user vault (config/permissions/files/search/sync)
```

**Дополнительно реализовано (после исходного плана):**

## Критерии приёмки (актуально)

1. Вход под тем же аккаунтом — изоляция чатов/задач/заметок/вольта. ✅ (API/логика)
2. Голосовой диалог и озвучка через сервер. ✅ (требует проверки на устройстве)
3. Быстрый запуск (виджет/плитка/ярлыки). ✅ в коде
4. Календарь и задачи: создание и управление. ✅
5. Заметки Open WebUI и личный Obsidian-вольт с правами. ✅
6. Приватный режим без сохранения истории. ✅
7. Сборка и раздача через GitHub Actions/Releases. ✅
8. Полный прогон на реальном устройстве — **ожидает тестирования**.

## Безопасность

- Токен в `EncryptedSharedPreferences`, HTTPS, биометрия опционально.
- Приватный режим: `FLAG_SECURE`, временные чаты.
- Права вольта проверяются программно на сервере при каждом действии.
- Секреты и ключи не в APK и не в репозитории.

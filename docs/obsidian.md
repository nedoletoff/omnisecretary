# Obsidian-вольт: требования и проектное решение

Статус: **проектирование** (реализация — этап 4). Требования зафиксированы
пользователем 2026-11-09.

## Требования

1. Вольт живёт в **приватном git-репозитории** пользователя.
2. Подключается **через интерфейс**, без ручной правки compose/файлов на Pi.
3. Доступен **только владельцу** (одному пользователю), не другим аккаунтам.
4. ИИ создаёт в вольте **отдельные папки** и пишет туда; чужие заметки не ломает.
5. Любая запись ИИ — **git-коммит**; синхронизация с origin.
6. Токен на чтение/запись выдаёт пользователь; токен не попадает в git и в чат.
7. **Экономия токенов и контекста:** не грузить вольт целиком, искать и
   читать только нужное.

## Архитектура (предлагаемая)

```
Open WebUI ──(MCP, bearer)──▶ obsidian-mcp ──▶ ${DATA_ROOT}/vault (git clone)
      │                            │                    │
      │                            └── SQLite FTS5 индекс (не в git)
      │
      └──(admin UI)──▶ vault-sync ── git pull/commit/push ──▶ origin (private repo)
```

Два сервиса:

### `vault-sync` — подключение и синхронизация

- Лёгкий сервис (Python/ARM64), том `${DATA_ROOT}/vault`.
- Веб-форма `/vault/` (HTTP Basic, пароль администратора из `.env`):
  repo URL, branch, PAT, кнопка «Подключить» / «Синхронизировать сейчас».
- Токен хранится в `${DATA_ROOT}/vault/.credentials` (права 600, вне git)
  либо в env сервиса; в URL репозитория не попадает.
- Клонирование: `git clone --branch <b> https://<token>@host/...` через
  credential helper, чтобы токен не оседал в `.git/config`.
- Синхронизация: `git pull --rebase` → локальные коммиты → `git push`.
  Конфликт: локальная версия откладывается в `AI/Conflicts/`, пользователю
  приходит уведомление в Telegram.

### `obsidian-mcp` — инструменты для ИИ

MCP-сервер с bearer-токеном (`VAULT_MCP_TOKEN`). Инструменты:

| Инструмент | Что делает | Токены |
|---|---|---|
| `vault_map()` | дерево папок + заголовки + теги (кэш, ~1–2 КБ) | мало |
| `vault_search(q, folder?, limit=5)` | FTS5-поиск, возвращает путь + заголовок + сниппет 3 строки | мало |
| `vault_read(path, offset=0, limit=200)` | чтение заметки постранично | по требованию |
| `vault_list(folder, depth=1)` | список файлов | мало |
| `vault_create(path, content)` | создать заметку + коммит | — |
| `vault_append(path, content)` | дополнить заметку + коммит | — |
| `vault_update(path, old, new)` | точечная замена + коммит | — |

Правила экономии контекста (зашиты в промпт пресета Archivist и в описание
инструментов):
- сначала `vault_search`, потом `vault_read` только найденного файла;
- не читать больше 2–3 заметок за один шаг;
- `vault_map()` — единственный «обзорный» вызов, и только при первом
  обращении к вольту в диалоге;
- никогда не пересказывать содержимое вольта целиком.

## Структура папок ИИ

```
AI/
├── Inbox/        быстрые захваты («запиши, что…»)
├── Notes/        структурированные заметки
├── Summaries/    выжимки диалогов
├── Daily/        утренние брифинги
└── Archive/      устаревшее
```

Человеческие папки не перезаписываются: запись только в `AI/*` и только
новых файлов или дополнение существующих. Правка чужих заметок — по явной
команде пользователя.

## Коммиты

- Один коммит на операцию записи:
  `vault: append AI/Notes/2026-11-09.md (OmniSecretary)`.
- Push: сразу после коммита, с debounce 60 секунд, чтобы не спамить origin.
- При недоступности сети коммит остаётся локально, push повторяется позже.

## Доступ только владельцу

- MCP-сервер принимает только bearer-токен; токен знает только Open WebUI.
- В Open WebUI MCP-подключение и инструменты вольта включены в пресетах
  `Secretary`, `Omni`, `Archivist`; доступ к этим пресетам — только у
  аккаунта владельца (model access control).
- Другие пользователи видят пресеты без инструментов вольта.
- Отдельный контейнер не имеет доступа к docker.sock и к сети кроме
  `backend` + исходящего HTTPS для git.

## Что нужно от пользователя (этап 4)

1. URL приватного репозитория и ветка.
2. Fine-grained PAT: доступ только к этому репозиторию, права
   `Contents: read/write`. Срок — 90 дней.
3. Подтверждение структуры папок `AI/*` (можно изменить до реализации).

## Открытые вопросы

- Нужен ли двусторонний просмотр вольта внутри Open WebUI (страница-браузер)
  или достаточно MCP + Obsidian на телефоне/десктопе?
- Пуш после каждой записи или раз в N минут (сейчас: debounce 60 с).

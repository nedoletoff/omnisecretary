# Быстрый доступ: календарь и заметки на отдельном домене

Короткий адрес для телефона и закладок:

```
https://nedoletoff.mooo.com
```

Открывается сразу страница «Календарь и заметки» портала. Вход — те же
аккаунты, что в Open WebUI (логин и пароль), отдельной регистрации нет.

## Что доступно

| Раздел | Действия |
|---|---|
| Календарь | список событий на 30 дней, создание (название, дата, время, длительность), удаление |
| Заметки | список заметок Open WebUI, создание и удаление |

Чат, настройки и админка на этом домене недоступны: `location /` отдаёт
редирект на `/portal/quick`, всё остальное — на основной домен.

## Как устроено

```
браузер → nginx (mooo.com, TLS) → portal:8000 → Open WebUI API
                                   │
                                   └ сессия портала (cookie) хранит JWT
                                     пользователя, поэтому запросы идут
                                     от его имени, а не от админа
```

Изоляция сохраняется: календарь и заметки каждого пользователя видны только
ему, потому что портал использует JWT из его сессии. Админский ключ не
применяется.

## Сертификат

Выпущен Let's Encrypt для `nedoletoff.mooo.com` (до 15.02.2027), продление —
тот же cron, что и для основного домена:

```bash
make renew-certs
```

DNS: A-запись `nedoletoff.mooo.com` → белый IP SkyNet. Порты 80/443 на
роутере проброшены на Pi (см. `docs/router.md`).

## Ограничения

- Нет офлайн-режима и PWA-манифеста — это лёгкая страница, не приложение.
- Заметки — это заметки Open WebUI, а не Obsidian. Obsidian доступен через
  `/vault/` и MCP-инструменты в чате.
- Если портал перезапущен, сессия сохраняется (cookie подписана
  `PORTAL_SECRET`, живёт 7 дней).
